# Employee Management System

## 📌 Project Overview

The Employee Management System is a Django-based web application that performs CRUD (Create, Read, Update, Delete) operations for managing employee records.

## 🚀 Features

- Add Employee
- View Employee List
- Update Employee Details
- Delete Employee Records
- Bootstrap Responsive UI
- Success Messages
- SQLite Database

## 🛠️ Technologies Used

- Python 3
- Django 5
- HTML5
- CSS3
- Bootstrap 5
- SQLite3

## 📂 Project Structure

```
employee_management/
│
├── manage.py

```

## 📋 Employee Fields

- Employee ID
- Employee Name
- Department
- Designation
- Email
- Phone Number
- Salary
- Date of Joining

## ▶️ Installation

Clone the repository:

```bash
git clone https://github.com/YOUR_USERNAME/Employee-Management-System.git
```

Move into the project folder:

```bash
cd Employee-Management-System
```

Install Django:

```bash
pip install django
```

Run migrations:

```bash
python manage.py makemigrations
python manage.py migrate
```

Start the server:

```bash
python manage.py runserver
```

Open your browser:

```
http://127.0.0.1:8000/
```
